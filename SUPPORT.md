## Ask the community

Questions, server setups, ideas and showcases: **[Discord](https://discord.gg/xpSuYgEYsU)**.

Please ask "how do I..." questions there rather than in an issue: more people see
them, and the answer helps the next person who searches the server.

## Report a problem

- **A bug**: open an issue with the *Bug report* form in the repository concerned
  (usually [opx_infinity](https://github.com/opx77-framework/opx_infinity/issues/new/choose)).
  Include the OPX version, both Open77 builds and the journal lines.
- **A documentation error**: the *Documentation issue* form in
  [opx77_doc](https://github.com/opx77-framework/opx77_doc/issues/new/choose).
- **A security vulnerability**: never in public. Follow [SECURITY.md](SECURITY.md).
